휴리스틱 평가란?

Jakob Nielsen이 제안한 10가지 사용성 원칙(휴리스틱)을 기준으로 전문가가 인터페이스를 평가하는 방법입니다. 사용성 테스트 전 주요 문제를 빠르게 발견하는 데 효과적입니다.

  • 평가자: UX 전문가 3~5명 권장 (1명도 가능)
  • 소요 시간: 1~2시간
  • 심각도: 1(외형적) ~ 4(치명적) 4단계로 분류
  • 산출물: 휴리스틱별 이슈 목록 + 심각도 분포 + 레이더 차트

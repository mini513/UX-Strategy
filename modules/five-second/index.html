Five Second Test

Five Second Test란?
UI 화면을 5초간 보여준 뒤, 사용자가 무엇을 기억하는지 확인하는 테스트입니다.
  • 첫인상과 시각적 위계(Visual Hierarchy)를 검증합니다.
  • 사용자가 5초 내에 핵심 요소를 인지하는지 확인합니다.
  • 브랜드 메시지, CTA, 내비게이션 등의 가시성을 평가합니다.
  • 키워드 빈도 분석을 통해 사용자의 인지 패턴을 파악합니다.
